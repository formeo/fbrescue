# Выгрузка базы Firebird в CSV и Excel

[fbrescue](https://github.com/formeo/fbrescue), бесплатная утилита с открытым кодом (лицензия MIT), записывает каждую таблицу базы Firebird 2.5–5.0 в отдельный CSV-файл прямо из файла базы, без сервера, ODBC-драйвера и пароля. Скачайте бинарник для своей системы на странице [Releases](https://github.com/formeo/fbrescue/releases/latest) и выполните:

```
fbrescue export shop.fdb --out data
```

```
data/
  schema.sql        операторы CREATE TABLE
  CUSTOMERS.csv     по файлу на таблицу
  ORDERS.csv
  _errors.jsonl     только если какие-то строки не прочитались
```

Чтобы выгрузить только некоторые таблицы, используйте `--table ИМЯ` (можно несколько раз). Если базой пользуется сервер, сначала сделайте копию файла: копия, снятая во время записи, может быть несогласованной.

## Как выглядит CSV

- **Формат.** RFC 4180: значения через запятую, первая строка — названия колонок, кодировка UTF-8, кавычки там, где они нужны.
- **NULL и пустая строка различаются.** NULL — пустое поле, пустая строка — `""`.
- **Числа точные.** `NUMERIC(18,2)` выгружается как `1234.50`, а не как число с плавающей точкой.
- **Даты, время, логические значения.** Даты `2024-02-29`, время `13:45:00.0000`, метки времени `2024-02-29 13:45:00.0000`, логические значения `true` / `false`.
- **BLOB.** Текстовые BLOB записываются целиком, двоичные значения — в шестнадцатеричном виде.
- **`CHARACTER SET NONE`.** Для текста в этой кодировке добавьте `--charset WIN1251` (или кодировку, с которой работала программа), чтобы получить читаемый UTF-8.

## Открыть в Excel

Если открыть CSV двойным щелчком, Excel сам угадывает кодировку и разделитель. Русский текст при этом ломается, а при русских региональных настройках ещё и колонки: Excel ждёт точку с запятой. Правильно так: **Данные → Из текстового/CSV-файла**, выберите файл, в поле *Источник файла* укажите **65001: Юникод (UTF-8)**, разделитель — **Запятая**, затем **Загрузить**. LibreOffice Calc спрашивает то же самое в окне импорта.

### Двойным щелчком: `--excel`

Если в Excel десятичный разделитель — запятая (так в России, Бразилии и большей части Европы), `fbrescue export old.fdb --out data --excel` запишет CSV, который открывается двойным щелчком: с BOM, чтобы Excel узнал UTF-8, с `;` между полями и десятичной запятой в числах. Текст, даты и время не меняются. При двойном щелчке тип колонки не выбрать, поэтому две вещи Excel сделает по-своему: коды, которые хранятся текстом, но похожи на числа (`00123`, индексы, ИНН), потеряют ведущие нули, а числа длиннее 15 цифр (идентификаторы `BIGINT`, `NUMERIC(18)`) — точность. Для таких колонок используйте импорт, описанный выше, и задайте колонке тип *Текстовый*.

## Другие форматы

- `--format jsonl`: по JSON-объекту на строку, точные числа — числами JSON. Удобнее всего для Python, Node или `jq`.
- `--format sql`: операторы INSERT и `schema.sql`, чтобы загрузить данные в другую базу Firebird через `isql`.
