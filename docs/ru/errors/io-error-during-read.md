# `I/O error during "read" operation for file`

В Windows операция называется `"ReadFile"`. Следом обычно идёт `Error while trying to read from file`, иногда с `Reached the end of the file` или ошибкой операционной системы.

## Что это значит

Движок попросил у операционной системы страницу и не получил её. Возможны две причины:
- страница лежит за концом файла: файл короче, чем считает база (копирование остановилось на середине, кончилось место на диске, оборвалась загрузка);
- диск не смог её прочитать.

Если сбоит диск, **перестаньте им пользоваться**: каждое чтение может сделать хуже. Сначала скопируйте файл на другой диск, при необходимости программой, которая пропускает нечитаемые сектора (`ddrescue` в Linux), и работайте с копией.

Если файл обрезан, страницы за концом потеряны, а с ними и строки на них. Всё, что до обрыва, можно спасти.

`gbak` часто останавливается на первой же странице, которую не может прочитать, даже если большая часть базы цела.

{% include fbrescue-ru.md %}

Для обрезанного файла `fbrescue scan` покажет страницы, на которые есть ссылки, но которых уже нет в файле, и таблицы, которым они принадлежат. Выгрузка читает все страницы, которые остались, и перечисляет строки и значения, которые прочитать не удалось. BLOB, чьи страницы пропали, записываются как NULL, остальная строка сохраняется.
